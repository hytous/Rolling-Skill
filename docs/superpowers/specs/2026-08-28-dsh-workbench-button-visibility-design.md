# DSH Rolling Skill 工作台按钮可见性与响应式布局设计

## 背景

DSH Button primitive 的 `ghost` 变体默认透明且无边框，只在悬停时显示背景。Rolling Skill 工作台把它用于刷新、详情、运行、编辑等内容区文本操作，导致默认态缺乏按钮可供性。Button primitive 同时使用固定的 28px/36px 高度，但允许文字换行和 Flex 收缩；操作区空间不足时，文本可能换成两行并超出固定高度。现有 760px 窄屏规则还会把面板标题、列表行和表单行的所有子项拉伸为整行，使小型刷新、详情和导入按钮产生不自然的满宽外观。

本次只统一 DSH Rolling Skill Client 的按钮语义和工作台布局，不改变任何 Case、Skill、安装、评测、优化或 Runtime 行为。

## 已确认方案

采用语义分级，而不是给所有按钮机械加边框，也不逐页面添加零散宽度修补。

### 主操作

- 保持现有 DSH `primary` 按钮视觉，不覆盖其填充色、圆角或交互状态。
- 每个局部流程继续由现有代码决定哪个动作是主操作，本轮不重新排序业务动作。

### 内容区文本操作

- 刷新、详情、导入、运行、保存、编辑、删除、分页、重试和其他可执行文本操作，默认态必须具有可见的细边框和轻量背景层。
- 使用 DSH theme token，不写固定颜色。
- 危险操作不在本轮引入新的组件 API；现有删除、废弃、拒绝等操作先使用同一可见次级按钮规则，避免扩大功能范围。

### 导航与真正弱操作

- 一级和二级导航保留现有未选中 `ghost`、选中 `outline` 的规则，因为导航容器和选中态已经表达其交互语义。
- 纯图标关闭按钮及明确的链接式操作可以继续使用 `ghost` 或无边框链接样式。
- 内容面板中的普通文本按钮不得仅依靠悬停表达可点击性。

## 组件与样式边界

- 在 Client 侧新增一个轻量 `ActionButton` 包装组件，默认使用 `outline`，透传 DSH Button 的尺寸、禁用态、点击事件和其他属性。只有明确指定 `tone="primary"` 或 `tone="quiet"` 时才映射为 `primary` 或 `ghost`。
- 工作台一级、二级导航继续直接使用 DSH `Button`，避免内容动作规则误伤导航视觉。
- 会话消息旁的“沉淀 Case”入口继续保持原生、紧凑的会话动作外观；本轮只覆盖工作台与其弹窗中的文本操作。
- 逐步将工作台各面板中的内容区 DSH `Button` 切换为 `ActionButton`。业务 props 与事件处理保持原样。

## 响应式布局规则

- 所有工作台按钮在操作行内使用 `flex: 0 0 auto`，禁止被压缩成小于内容宽度。
- 按钮文本保持单行；空间不足时移动整颗按钮，不允许在固定高度内换成两行。
- `.rolling-skill-actions` 允许换行，并保持按钮内容宽度。
- `.rolling-skill-form-row` 中的主输入控件继续使用剩余宽度且允许收缩，按钮保持内容宽度。
- 760px 以下，面板标题、列表行和表单行仍可改为纵向，但使用 `align-items: flex-start`；输入框、Select、文本区域和信息主体可以占满宽度，普通按钮不被强制拉满。
- 对需要满宽的唯一主要动作，由调用方显式添加满宽类；不再依靠通用窄屏规则隐式拉伸所有按钮。

## 错误与状态行为

按钮样式调整不改变 loading、disabled、error 或业务执行逻辑。禁用态继续由 DSH primitive 处理；换行只发生在按钮之间，不改变按钮标签。工作台数据请求、路由和弹窗行为保持不变。

## 测试与验收

- 源码测试证明工作台内容区使用统一 `ActionButton`，导航继续使用 DSH `Button`。
- CSS 合约测试证明操作按钮禁止收缩和文本换行，操作区允许换行，窄屏下普通按钮不会被无差别拉满。
- `npm run test:dsh`、Client 构建和插件包检查必须通过。
- 安装新插件版本后，在真实 DSH 浏览器中以约 650px 宽工作台检查：
  - 页面内刷新、详情、运行等文本操作默认态可识别；
  - 小按钮保持内容宽度；
  - 长标签不在固定高度内换行或溢出；
  - 操作空间不足时整颗按钮换行；
  - 主按钮和两级导航的视觉层级不被破坏。

## 非目标

- 不修改 DSH primitive 包本身。
- 不让所有按钮具有相同宽度。
- 不重新设计导航、卡片、表单字段或业务流程。
- 不新增危险按钮色彩 API、图标体系或动画。
- 不处理 Electron 版本的按钮样式。
