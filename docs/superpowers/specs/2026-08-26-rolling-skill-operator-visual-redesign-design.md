# Rolling Skill 自操作工作台视觉重构设计

## 背景

上一轮已经完成中文化、主题变量接入和基础圆角调整，但本机 App 的实际截图显示，页面仍然沿用三个等权大面板：左、右栏使用大面积发蓝底板，中间把所有配置堆成普通表单，空数据也强制占据整栏。结果是信息层级弱、留白失衡、主操作不突出，视觉上仍像临时管理后台，未达到现有 Rolling Skill 界面的完成度。

本次只重构自操作工作台的布局与视觉层级，不改变 Operator、Job、审批、预算或多 Epoch 优化的业务行为。

## 已确认方向

采用“任务轨道 + 主操作画布 + 上下文摘要栏”的三栏方案：保留三栏功能边界，但取消三个大卡片等权并列的观感。主流程由中间画布承载，左右栏退回辅助导航和上下文角色。

不采用以下方案：

- 单栏向导：视觉更简单，但会改变现有任务、会话和状态同时可见的工作方式。
- 继续微调现有三框结构：改动小，但无法解决等权面板、空栏占位和主流程不突出的根因。

## 页面骨架

### 工作区背景

- 使用现有 `var(--surface)` 作为连续工作区背景，移除自操作页的径向渐变和整页蓝色铺底。
- 三栏之间使用间距与细分割线建立结构，不再给每一栏都套同样的粗边框、圆角和底色。
- 桌面宽度下，左侧任务轨道约 `168–188px`，右侧摘要栏约 `218–242px`，剩余空间全部给中间主画布。

### 左侧任务轨道

- 采用紧凑导航栏，而不是独立大卡片。
- 顶部只保留“任务”标题与蓝色“新建任务”主入口；弱化重复的“自操作”kicker。
- 任务项使用现有列表的 hover、选中态和辅助文字层级；不再使用整栏浅蓝背景。
- 空态靠近列表顶部显示，不在栏内大面积居中。

### 中间主操作画布

- 主画布使用 `var(--surface)`，只保留左右细分割线，不再像嵌套在蓝色容器中的大表单卡。
- 标题区包含页面标题和一句说明，之后直接进入配置内容。
- “目标”是首要输入，置于标题后并横跨整行。
- 配置按三个视觉分组组织：
  1. 运行环境：任务类型、Runtime、模型、推理强度。
  2. 资源范围：受管 Skill、数据集、允许操作的目标 Runtime。
  3. 权限与预算：保持可折叠，但样式改成普通分组行，不使用发蓝的胶囊横条。
- 分组依靠小标题、间距和细分割线，不为每组重复套卡片。
- 目标 Runtime 使用紧凑的标签式选择项，选中态使用主题 accent，避免原生复选框散落在空白框中。
- 底部操作区贴近配置内容：左侧显示必要提示，右侧使用明确的蓝色 Primary 按钮；删除页面底部重复的灰色空态说明。
- 会话模式沿用同一画布，标题、状态、控制按钮、消息列表与输入区保持统一层级。

### 右侧上下文摘要栏

- 右栏不再使用整块浅蓝卡片，只保留紧凑分区和分割线。
- 新建任务且暂无数据时，空态文字弱化，不让五个空分区形成视觉主角。
- 任务运行后按“作用范围、预算、子任务、产物、审批”展示有效内容；审批等需要行动的内容才使用强调色。
- 右栏只承担摘要与行动提醒，不与中间主流程争夺视觉重量。

## 视觉语言

- 继续只使用已有主题变量，包括 `--surface`、`--surface-raised`、`--surface-hover`、`--border`、`--accent`、`--accent-ink`、`--muted` 和状态色。
- 页面标题、字段标签、辅助文本、列表标题按现有 Skill 评测页的字号层级统一；不使用大面积全大写或过小字体。
- 输入框和选择器保持统一高度、圆角和边框；focus 使用 accent，不使用黑色默认描边。
- 主按钮使用 accent 实心样式，次要操作使用中性边框，危险色只用于停止、拒绝和失败。
- 阴影只用于需要浮层感的输入操作区，不给所有面板同时加阴影。

## 响应式行为

- 常规桌面宽度保持三栏。
- 可用宽度不足时先缩窄左右辅助栏，再让右栏落到主画布下方；不压缩中间表单到不可用宽度。
- 不改变现有可访问名称、键盘操作或中英文翻译键。

## 实现边界

- `renderer/index.html`：只增加表达视觉分组所需的语义 class 或轻量容器，不改变字段、ID 和提交结构。
- `renderer/styles.css`：重写自操作工作台布局、分组、选择项、摘要栏和操作按钮样式。
- `renderer/operator-workbench.js`：仅在视觉分组需要动态 class/空态状态时做最小调整，不改变请求和状态机。
- 不新增图片、图标库、主题变量、业务数据或新的配置步骤。

## 验收标准

- 本机 App 中，自操作页不再呈现三个发蓝的大卡片并排，也没有中间表单下方的大面积无意义留白。
- 左栏明确是任务导航，中间明确是唯一主操作区，右栏明确是次要摘要，视觉权重有明显主次。
- 新建页的目标、运行环境、资源范围、权限预算和开始按钮能够按顺序快速扫描。
- 主按钮使用现有主题的蓝色 Primary 样式，字段 focus 不出现默认黑框。
- 中文与英文切换继续使用 Settings 的既有语言设置，布局不会因语言变化破坏。
- 重新打包安装后，直接打开本机 App，在“自操作”页进行截图级视觉检查。
- 自动化只运行与此次 DOM/CSS 结构直接相关的聚焦测试，不运行全量测试。

## 非目标

- 不调整全局左侧任务栏和顶部 Runtime 区域。
- 不修复本轮界面验证中出现的 Codex app-server 退出问题。
- 不改变自操作的功能范围、数据流、权限模型或优化流程。
